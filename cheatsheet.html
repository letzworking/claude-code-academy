Claude Code 치트시트

모니터 옆에 붙여 두고 쓰세요.

🚀 시작하기

claude현재 폴더에서 대화 시작
claude "질문"질문과 함께 바로 시작
claude -c가장 최근 대화 이어하기
claude -r지난 대화 골라서 이어하기
claude -p "질문"한 번 답하고 종료 (스크립트용)

⌨️ 꼭 알아야 할 키

Esc하던 일 멈추기
Esc Esc이전 시점으로 되감기
Shift+Tab권한 모드 전환 (Plan 모드 포함)
Shift+Enter줄바꿈 (여러 줄 입력)
↑이전 입력 불러오기
@파일명특정 파일을 지목해서 질문
!명령셸 명령 바로 실행 (예: !git status)

/ 자주 쓰는 명령

/help사용 가능한 명령 보기
/initCLAUDE.md 초안 만들기
/clear새 대화로 시작
/compact긴 대화를 요약해 정리
/rewind이전 시점으로 되돌리기
/review변경 내용 리뷰받기
/model사용할 모델 바꾸기
/doctor설치 상태 점검
/exit종료

🧩 좋은 요청의 4요소

대상"OrderService의 cancel()"
목표"재고 복구가 안 되는 원인 찾기"
제약"다른 클래스는 건드리지 마"
검증"테스트 만들고 통과시켜줘"

📋 바로 쓰는 프롬프트

코드 이해
{클래스}가 하는 일을 요약하고, 수정할 때 조심할 점을 알려줘.
버그 찾기
{클래스}에서 잠재적 버그를 심각도 순으로 찾아줘. 아직 수정하지 마.
테스트
{클래스} 단위 테스트를 JUnit 5 + Mockito로 만들고 실행해서 통과시켜줘.
쿼리
{Mapper.xml}의 {쿼리ID}가 조건별로 어떤 SQL이 되는지 보여주고 성능 위험을 짚어줘.
버그 수정
이 에러의 원인을 찾고, 재현 테스트를 먼저 만든 뒤 최소한으로 고쳐줘.
(스택트레이스)
PR 설명
main 대비 변경 내용으로 PR 설명을 써줘. 배경/변경/테스트/리뷰 포인트 형식으로.
