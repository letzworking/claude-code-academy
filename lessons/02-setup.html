설치와 첫 실행

  • ⏱ 10분
  • 🛠 실습
이 레슨을 마치면
  • Claude Code가 설치되어 있고 로그인이 끝나 있습니다.
  • 내 프로젝트 폴더에서 첫 질문을 던져 봅니다.

준비물

  • Claude 유료 계정 — Pro·Max·Team·Enterprise 요금제 또는 Claude Console(API) 계정. 무료 요금제로는 사용할 수 없습니다.
  • 터미널 — Windows는 PowerShell, macOS는 터미널 앱이면 충분합니다.
  • 연습할 프로젝트 하나 — 평소 작업하는 Java 프로젝트면 가장 좋습니다.
⚠️

회사 PC라면 설치 전에 사내 소프트웨어·AI 사용 정책을 확인하세요. 어떤 계정을 쓸지도 팀에 먼저 물어보는 것이 좋습니다.

  1. 설치하기

    운영체제에 맞는 명령을 복사해 터미널에 붙여넣으세요.

    PowerShell
    irm https://claude.ai/install.ps1 | iex

    WinGet을 쓴다면 winget install Anthropic.ClaudeCode도 됩니다. Git for Windows가 설치되어 있으면 더 매끄럽게 동작합니다(권장).

    Terminal
    curl -fsSL https://claude.ai/install.sh | bash

    Homebrew 사용자는 brew install --cask claude-code도 가능합니다.

    Node.js 22 이상
    npm install -g @anthropic-ai/claude-code

    이미 Node.js 환경을 쓰고 있다면 이 방법도 됩니다.

    설치가 끝나면 터미널을 새로 열고 버전이 나오는지 확인합니다.

    확인
    claude --version

  2. 프로젝트 폴더에서 실행하기

    Claude Code는 실행한 폴더를 작업 범위로 삼습니다. 그래서 항상 프로젝트 루트로 이동한 뒤 실행합니다.

    예시
    cd C:\work\order-service
claude

  3. 로그인하기

    처음 실행하면 브라우저가 열리며 로그인 화면이 나옵니다. 로그인하고 돌아오면 끝입니다. 이 과정은 한 번만 하면 됩니다.

    브라우저가 자동으로 열리지 않으면 화면 안내에 따라 c를 눌러 로그인 주소를 복사해 직접 열면 됩니다.

  4. 첫 질문 던지기

    입력창이 보이면 아래 문장을 그대로 붙여넣어 보세요.

    첫 프롬프트
    이 프로젝트가 어떤 일을 하는지, 주요 패키지 구조와 함께 5줄로 요약해줘.

    Claude가 파일을 둘러보고 요약을 돌려줄 겁니다. 이 질문은 파일을 읽기만 하므로 아무것도 바뀌지 않습니다.

승인 요청 화면 이해하기

Claude가 파일을 수정하거나 명령을 실행하려 할 때, 설정에 따라 "이 작업을 해도 될까요?"라고 묻습니다. 무엇을 하려는지 보여주므로 내용을 읽고 선택하면 됩니다.

선택의미언제
허용이번 한 번 실행내용을 확인했고 문제없을 때
항상 허용같은 종류의 작업은 다시 묻지 않음./gradlew test처럼 안전한 명령이 반복될 때
거절 + 의견실행하지 않고 다른 방향을 지시"그 파일 말고 Service 쪽만 고쳐줘"

Shift+Tab으로 권한 모드를 바꿀 수 있습니다. 매번 확인받는 모드, 파일 수정은 자동으로 허용하는 모드, 계획만 세우고 수정은 하지 않는 Plan 모드 등이 있습니다. 처음에는 하나씩 확인받는 방식으로 시작해 Claude가 어떻게 일하는지 지켜보길 권합니다.

당황했을 때 기억할 세 가지

Esc 지금 하던 일 멈추기 · EscEsc 이전 시점으로 되감기 · /exit 종료

IDE에서 쓰고 싶다면

터미널이 익숙하지 않다면 평소 쓰는 IDE에서도 사용할 수 있습니다.

IntelliJ IDEA

JetBrains Marketplace에서 Claude Code 플러그인을 설치합니다. 위에서 설치한 CLI를 IDE 안에서 실행하고, 변경 내용을 IDE의 diff 화면으로 보여줍니다.

VS Code

확장 마켓플레이스에서 Claude Code를 검색해 설치합니다. 채팅 패널과 인라인 diff로 변경 사항을 확인할 수 있습니다.

문제가 생기면 Claude Code 안에서 /doctor를 입력해 설치 상태를 점검할 수 있습니다. 자세한 설치 안내: 공식 설치 문서
